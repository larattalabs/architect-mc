## Decisions so far (to the as-built section)

- `block` and `class` terms: ARSV has no top block and ARVX holds voxel classes only, so neither is available "from the
  column's top". `class` reads the IR's frozen volumes (ARVX side blobs); `block` needs a frozen block volume, which the mod
  doesn't sample yet, so a plan whose mask names `block` is refused (typed). Open ruling for the coordinator.
- `toolbox` on crater_works is a bool param with `omitDefault` (kit params): off, it stays out of the resolved params, so the
  default seed, the IR and the tile shas don't move (item 8).
- The gradient dither is an ordered 4x4 matrix with one threshold from each quarter in every row and column (not Bayer's own
  matrix: its column of mid thresholds draws a straight edge on a 3-high interval, failing item 2's run bar).
- apijars / api-compat: 0.17.0 (gate6c-mp/v0170), 0.16.0, 0.15.0. W does the same with its own v0170 copy; at the merge take
  the then-previous three.
